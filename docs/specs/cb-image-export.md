# cbImageExport（画像一括書き出しくん）仕様たたき台

## 概要

対象フレーム内の可視画像を一覧し、PNG / JPG / SVG / PDF で個別・一括書き出しする。

## 対象フレームの選択

- 選択状態（`selectionchange`）の自動追従は行わない
- cbTextChecker と同じ対象ピッカーで選択する（UI は [`../../cbTextChecker/src/targetPicker.ts`](../../cbTextChecker/src/targetPicker.ts) に準拠）
- ピッカーは現在ページの SECTION / FRAME / INSTANCE / GROUP を候補として一覧する
- ピッカーをクリック → 現在の Figma 選択から対象フレームを解決（選択ノードか直近の祖先）。未選択の場合は候補のポップオーバーを開く
- 対象フレームが決まると自動で画像一覧を更新する。候補外・見つからない場合はフレーム未選択扱い

## 一覧ルール

- 表示されているノードのみ（`visible === false` の枝は除外）
- `clipsContent` 付きの親フレーム・スロットに属する画像は、**その枠を 1 行**として一覧（枠の切り抜かれた見た目がそのままサムネイル・書き出し・リネーム・フォーカスの対象。中身の画像数は問わない）
- マスクコンテナに属する画像は**そのマスクコンテナを 1 行**として一覧（中身の画像数は問わない）
- クリップ・マスクがない場合は画像ノードを**1 件ずつ**一覧
- マスクノード（`isMask`）自身は一覧に出さない
- インスタンス・スロット内部の画像も一覧対象に含む（`findAll` ベースの走査、`skipInvisibleInstanceChildren = false` を明示）

## UI

- ヘッダーにアイコンボタンの「書き出し」（ダウンロード）「再読み込み」（リロード）と対象フレームピッカー、「すべて」チェック
- 画像一覧行: チェック / サムネイル / レイヤー名（編集可能） / 除外アイコン / 書き出しアイコン / 「+」ボタン
- 行の書き出しアイコンは**その行の書き出し設定すべて**を書き出し（チェックは不要。設定が無い場合はエラー表示）
- レイヤー名は変更すると Figma 上のレイヤー名と書き出しファイル名に反映
- 書き出し設定（形式・サイズ）も変更すると **Figma レイヤーの書き出し設定（`exportSettings`）に反映**（空にするとクリア）。逆に再スキャン時はレイヤーのエクスポート設定（`SCALE` / `WIDTH` / `HEIGHT`）を一覧へ反映（双方向同期）
- 「+」を押すとその画像に書き出し設定（サイズ + 形式 + 「-」）が追加される。複数追加で複数ファイル書き出し
- サイズ入力は `1x` / `2x` / `0.5x` / `512w` / `512h` 形式。拡張子なしの純数字は `x` を補完し倍率（SCALE）として扱う。SVG / PDF はサイズ指定なし
- 行ごとに除外アイコン（cbTextChecker の ignore パターン）。クリックで「チェック項目を除外する」ポップオーバーを表示し、エフェクト / 線 / 角丸のチェックボックスをオンにすると**その項目を書き出しから除外**（デフォルトはすべてオン = 3項目とも除外）
  - 除外は**書き出し結果にのみ**適用（元レイヤーの見た目・`exportSettings` には反映しない）
  - 実装: 除外項目がある場合のみ対象ノードを一時クローンし、該当プロパティ（`effects` / `cornerRadius` / `strokes`）を行ノード自身から除去して書き出し、完了後即削除
- 「書き出し」はチェック済み画像のみ、各画像の書き出し設定すべてを実行
- 書き出し先は**フォルダ選択（`showDirectoryPicker`）**。クリック時にフォルダを1回選ぶだけで、全ファイル（`レイヤー名.ext`）を止まらず同一フォルダへ保存
  - フォルダ選択 API が使えない環境（Figma デスクトップアプリ等）では、全結果を **ZIP（`cbImageExport-時刻.zip`）にまとめて 1 ファイルでダウンロード**（`fflate` 圧縮・重複名は `_2` 等で一意化）
  - ファイル名はサイズが `1x` 以外のとき `レイヤー名_<サイズ>.ext`（例: `_2x` / `_512w` / `_0.5x`）。`1x` は `レイヤー名.ext`。SVG / PDF はサイズ指定が効かないためサフィックスなし
- サイズ入力（倍率・寸法）は SVG / PDF では**非活性**（`disabled`）。ラスタ形式に戻すと入力値は保持され編集可能
- 形式は PNG / JPG / SVG / PDF / **WEBP**
  - WEBP は Figma の `exportSettings` に無いため、PNG でレンダリング → UI 側で `canvas.toBlob("image/webp")` に変換して保存
  - **圧縮率（%）入力**を形式の右に表示（PNG / JPG / WEBP のみ。既定 92、1〜100）。JPG / WEBP は `canvas.toBlob(mime, q/100)`、PNG は可逆のため **色数削減（median-cut + Floyd–Steinberg ディザリング + 自前パレット PNG エンコーダ）** で `(256 × q/100)` 色へ量子化して実圧縮（q=100 はそのまま）
  - PNG / JPG / WEBP / 品質はレイヤーの `exportSettings` に表現できない部分があるため、対象フレーム内の **1 つのセンチネルコンテナ `__cb_export__`**（0×0・`visible=false` / `locked=true` / 塗りなし）に集約して永続化
    - 中身は 0×0 矩形のセンチネル `__cfg__|<形式>|<行id>|<サイズ>|<品質>`（WEBP は常時、PNG/JPG は品質付き設定時）。設定変更で upsert / 解除で削除
    - 再スキャン時はセンチネルが同一形式のレイヤー設定を上書きして**品質を復元**し、行が消えた項目や旧 `__cb_webp__` レイヤーは掃除

## ホバーハイライト

- 一覧行にホバーすると、その行の対象ノードを `hoverEffect` という名前のハイライトで囲む（ルート＝`figma.currentPage` 直下、`locked` 状態）
- ビジュアルは cbTextChecker と同一（緑 40% 塗り + 破線ストローク）。ホバーが外れると非表示
- スキャン・ページ切替・プラグイン終了時にハイライトを非表示・破棄
