# cbImageExport（画像一括書き出しくん）仕様たたき台

## 概要

対象フレーム内の可視画像を一覧し、PNG / JPG / SVG / PDF で個別・一括書き出しする。

## 対象フレームの選択

- 選択状態（`selectionchange`）の自動追従は行わない
- cbTextChecker と同じ対象ピッカーで選択する（UI は [`../../cbTextChecker/src/targetPicker.ts`](../../cbTextChecker/src/targetPicker.ts) に準拠）
- ピッカーは現在ページの SECTION / FRAME / INSTANCE / GROUP を候補として一覧する
- ピッカーをクリック → 現在の Figma 選択から対象フレームを解決（選択ノードか直近の祖先）。未選択（解決不能）の場合は**「最近選択したフレーム」履歴ポップオーバー（最大 20 件・除外メニューと同形状）**を開く
  - 履歴は `figma.clientStorage` に永続化（プラグインを閉じても保持・直近が先頭・id 重複は移動）、起動時に削除済みフレームを掃除、対象確定時に記録
  - 履歴ポップオーバー下部の「候補一覧から選ぶ…」で従来の検索候補一覧を開ける
- 対象フレームが決まると自動で画像一覧を更新する。候補外・見つからない場合はフレーム未選択扱い

## 一覧ルール

- 表示されているノードのみ（`visible === false` の枝は除外）
- `clipsContent` 付きの親フレーム・スロットに属する画像は、**その枠を 1 行**として一覧（枠の切り抜かれた見た目がそのままサムネイル・書き出し・リネーム・フォーカスの対象。中身の画像数は問わない）
- マスクコンテナに属する画像は**そのマスクコンテナを 1 行**として一覧（中身の画像数は問わない）
- クリップ・マスクがない場合は画像ノードを**1 件ずつ**一覧
- マスクノード（`isMask`）自身は一覧に出さない
- インスタンス・スロット内部の画像も一覧対象に含む（`findAll` ベースの走査、`skipInvisibleInstanceChildren = false` を明示）
- **Figma 側で書き出し設定（`exportSettings`）を持つ画像以外のレイヤー**（図形・アイコン・グループなど）も独自の行として一覧に含む（行 = ノード自身。マスク・クリップの行解決は適用しない）。画像ノードは従来どおりの行解決で吸収されるため二重表示しない
- 一覧行の品質(%) は**形式の既定値のみ**を表示（PNG 100 = 無劣化 / JPG 92）。編集した値のみセンチネルで永続化。Figma の `exportSettings` に品質は無いため**Figma 側からは読まない**

## UI

- ヘッダーにアイコンボタンの「書き出し」（ダウンロード）「再読み込み」（リロード）と対象フレームピッカー、「すべて」チェック、**歯車（URL コピー設定）**
- 画像一覧行: チェック / サムネイル / レイヤー名（編集可能） / 除外アイコン / 書き出しアイコン / 「+」ボタン
- **書き出し先パス設定（歯車・ハンバーガーアイコン）**: 歯車をクリックすると「URL コピー設定」ポップオーバー（除外メニューと同形状）を開き、書き出し先パス（例 `/assets/images/`）を設定。**対象フレームごとに**設定し、`figma.clientStorage`（`cbImageExport.frameAssetPaths`、フレーム ID → パス）に永続化（対象切替でそのフレームのパスを表示・起動時に削除済みフレームのパスを掃除・対象未選択時は歯車を無効化）
- **URL コピー（行内の書き出し形式ごと・ハンバーガーアイコン）**: 各書き出し設定の品質入力の右にコピーアイコン。クリックでポップオーバーに「urlをコピー」ボタン + 生成 URL のプレビューを表示し、`現在の対象フレームのパス + 書き出しファイル名` をクリップボードへコピー（`navigator.clipboard`・不可なら `execCommand` にフォールバック）
  - ファイル名は書き出し時のルールと同一（例: `image01` を PNG(1x) で書出し設定なら `/assets/images/image01.png`、2x なら `/assets/images/image01_2x.png`）
- 書き出し形式の行は `<サイズ> <形式> <品質%> [コピー] [-削除]` の順で表示し、削除ボタン（`-`）が左端。設定一覧は行の左端（インデントなし）に揃える
- 行ヘッダーの除外・書き出し・`+` ボタンはレイヤー名入力欄と同じ縦幅（24px）の正方形に統一（ヘッダーの書き出し/再読込/歯車は 28px のまま）
- 行の書き出しアイコンは**その行の書き出し設定すべて**を書き出し（チェックは不要。設定が無い場合はエラー表示）
- レイヤー名は変更すると Figma 上のレイヤー名と書き出しファイル名に反映
- 書き出し設定（形式・サイズ）も変更すると **Figma レイヤーの書き出し設定（`exportSettings`）に反映**（空にするとクリア）。逆に再スキャン時はレイヤーのエクスポート設定（`SCALE` / `WIDTH` / `HEIGHT`）を一覧へ反映（双方向同期）
- 「+」を押すとその画像に書き出し設定（サイズ + 形式 + 「-」）が追加される。複数追加で複数ファイル書き出し
- サイズ入力は `1x` / `2x` / `0.5x` / `512w` / `512h` 形式。拡張子なしの純数字は `x` を補完し倍率（SCALE）として扱う。SVG / PDF はサイズ指定なし
- 行ごとに除外アイコン（cbTextChecker の ignore パターン）。クリックで「チェック項目を除外する」ポップオーバーを表示し、エフェクト / 線 / 角丸のチェックボックスをオンにすると**その項目を書き出しから除外**（デフォルトはすべてオン = 3項目とも除外）
  - 除外は**書き出し結果にのみ**適用（元レイヤーの見た目・`exportSettings` には反映しない）
  - 実装: 除外項目がある場合のみ対象ノードを一時クローンし、該当プロパティ（`effects` / `cornerRadius` / `strokes`）を行ノード自身から除去して書き出し、完了後即削除
- 「書き出し」はチェック済み画像のみ、各画像の書き出し設定すべてを実行
- 書き出し先は**フォルダ選択（`showDirectoryPicker`）**。クリック時にフォルダを1回選ぶだけで、全ファイル（`レイヤー名.ext`）を止まらず同一フォルダへ保存
  - フォルダ選択 API が使えない環境（Figma デスクトップアプリ等）では、全結果を **ZIP（`cbImageExport-時刻.zip`）にまとめて 1 ファイルでダウンロード**（`fflate` 圧縮・重複名は `_2` 等で一意化）
  - ファイル名はサイズが `1x` 以外のとき `レイヤー名_<サイズ>.ext`（例: `_2x` / `_512w` / `_0.5x`）。`1x` は `レイヤー名.ext`。SVG / PDF はサイズ指定が効かないためサフィックスなし
- サイズ入力（倍率・寸法）は SVG / PDF では**非活性**（`disabled`）。ラスタ形式に戻すと入力値は保持され編集可能
- 形式は PNG / JPG / SVG / PDF / **WEBP** / **AVIF**
  - WEBP / AVIF は Figma の `exportSettings` に無いため、PNG でレンダリングしてから UI 側で変換して保存
    - WEBP / JPG は `canvas.toBlob(mime, q/100)`（Chromium は対応 MIME のみ正しくエンコードし、非対応 MIME は**静かに PNG へフォールバック**するため、出力 MIME を検証して不一致ならエラー）
    - AVIF は **libavif の WASM（`@jsquash/avif`）** を base64 インラインで同梱し、`WebAssembly` で実エンコード（`canvas.toBlob("image/avif")` は Chromium 非対応で PNG 化するため不使用）。出力が `ftypavif` ブランドかを検証
  - **圧縮率（%）入力**を形式の右に表示（PNG / JPG / WEBP / AVIF のみ。1〜100）。JPG / WEBP は既定 92 で `canvas.toBlob(mime, q/100)`、AVIF は既定 92 で WASM エンコードの `quality`（q=100 は **lossless**）、PNG は可逆のため**既定 100（無劣化・量子化なし）**とし、**明示的に下げた場合のみ** 高品質量子化で `(256 × q/100)` 色へ変換して実圧縮
    - PNG 量子化は γ 線形化の**立方根（CIE-L* 近似）** 空間で 5bit ヒストグラム → k-means++ + Lloyd 収束でパレット構築し、プレマルチ立方根空間の **Floyd–Steinberg（蛇行・2 行バッファ）** でディザリング。ユニーク色 ≤ 色数なら**完全一致パレット**で量子化・ディザなし
    - `png.ts` は書き出し本体を DOM 非依存の純粋関数（`encodeQuantized` / `quantizeImageData`）とし、エンコードは自前パレット PNG エンコーダ（CRC-32 自前実装・deflate は fflate）
  - PNG / JPG / WEBP / AVIF / 品質はレイヤーの `exportSettings` に表現できない部分があるため、対象フレーム内の **1 つのセンチネルコンテナ `__cb_export__`**（0×0・`visible=false` / `locked=true` / 塗りなし）に集約して永続化
    - 中身は 0×0 矩形のセンチネル `__cfg__|<形式>|<行id>|<サイズ>|<品質>`（WEBP / AVIF は常時、PNG/JPG は**品質を明示設定したときのみ**）。設定変更で upsert / 解除で削除
    - 再スキャン時はセンチネルが同一形式のレイヤー設定を上書きして**品質を復元**し、行が消えた項目や旧 `__cb_webp__` レイヤーは掃除

## ホバーハイライト

- 一覧行にホバーすると、その行の対象ノードを `hoverEffect` という名前のハイライトで囲む（ルート＝`figma.currentPage` 直下、`locked` 状態）
- ビジュアルは cbTextChecker と同一（緑 40% 塗り + 破線ストローク）。ホバーが外れると非表示
- スキャン・ページ切替・プラグイン終了時にハイライトを非表示・破棄
