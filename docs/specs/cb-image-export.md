# cbImageExport（画像一括書き出しくん）仕様たたき台

## 概要

選択したフレーム内の可視画像を一覧し、PNG / JPG / SVG / PDF で個別・一括書き出しする。

## 一覧ルール

- 表示されているノードのみ（`visible === false` の枝は除外）
- IMAGE fill を持つノードを**1 件ずつ**一覧（マスク / `clipsContent` への集約はしない）
- マスクノード（`isMask`）自身は一覧に出さない

## UI

- ヘッダーに「書き出し」「再読み込み」ボタン（トグル）と対象フレーム表示
- 画像一覧: チェック / サムネイル / 対象名 / 親名 / 書き出し設定（倍率 + 形式）のリスト
- 「+」で1画像に書き出し設定を複数追加（複数ファイル書き出し）、設定行の「✕」で削除
- ヘッダーの「すべて」で一括チェック
- 「書き出し」はチェック済み画像のみ、各画像の書き出し設定すべてを実行
