# ADR-006: 一覧の表示モード（詳細 / 一覧 / サムネイル）

## コンテキスト

- 一覧の行は、サムネイルと名前に加えて「1200×800 · 12 要素 · 4.1 KB」という情報行を常に表示していた。テンプレートが増えても 1 行の高さは変わらないので、スクロール量だけが増える
- 要望は次のとおり
  - 絞り込みアイコンの左に表示切り替えのアイコンを足す
  - 詳細 / 一覧 / サムネイルの 3 つで切り替える
  - 詳細 = 今の見た目
  - 一覧 = サムネイルと名前のみ
  - サムネイル = 2 カラム。サムネイルと名前のみで、画像を大きくする。配置は画像が上、名前が下
- UI の幅は 360px で固定（`UI_WIDTH`）。`cbTemplatePalette` は幅を変えられないプラグイン

## 決定

### モードは CSS のクラスだけで切り替える

- 行の HTML はモードで作り直さない。`<ul class="template-list">` に `is-list` / `is-grid` を付けるだけで、入れ子の `<ul>` にも同じクラスを付ける
- この方式なら、選択・名前変更・複製・削除・グループの開閉と「移動」サブメニューは、モードに関係なくそのまま動く。モードごとに別の描画コードを書かないので、モードによって挙動が食い違う場所が出ない
- 一覧に出る項目はモードに依存しない。絞り込みの判定と `visibleNodes` はモードで分けず、共通のままにする

### 表示の好みを保存し、内容の tree には入れない

- `cbTemplatePalette.viewMode`（clientStorage）に保存する。`cbTemplatePalette.uiHeight` と同じ「見た目の好み」なので、同じ場所に置く
- ADR-005 では開閉状態を `tree` に入れた。ここでは入れない。`tree` は中身の構成と並び順で、どの端末でもどのファイルでも同じもの。表示モードは端末ごとの違い
- ファイル（`*.cbtemplate.json`）にも書き出さない
- 起動時は `TEMPLATES` に載せて渡す。これは `usedBytes` を載せているのと同じ形。未知の値は詳細に戻す

### ボタンはポップアップにする

- 絞り込みアイコンの左に置き、ポップアップから 3 つのモードを選ぶ。`menuitemradio` で現在のモードに印を出す
- 1 つのボタンで巡回させる案と、3 つのアイコンを並べた案は採用しなかった。3 つの絵を覚える必要がなく、押したあとの現在のモードが絵で分かるため
- ボタンの絵は現在のモードを表す。詳細 = サムネイル付き行、一覧 = 横線 3 本、サムネイル = 2×2 の四角

### サムネイルモードでも並べ替えは使えるままにする

- 前後の判定を、上下の半分から左右の半分に変える。上下の判定のままだと、左右に並ぶセルの位置を行の上と下に読み違える
- ヒントの線も左右の縦線にする
- グループの見出しは 2 セルを使い切って 1 行にし、開いた中身も同じモードで 2 カラムにする。見出しを 1 セルにすると「中身の件数」と「2 カラムに並んだ中身」の区別が読めなくなる
- サムネイルモードの「⋯」はセルの右上に置き、セルにカーソルがあるあいだだけ出す

## 結果

- 360px 幅での実測
  - サムネイルモード: 一覧の幅は 332px、セルは 162px、サムネイル枠は 150×113（4:3）。グループ見出しは 332px の 1 行で、入れ子も 2 カラム
  - 一覧はサムネイルを 32px にして行を 44px に詰める（詳細の 60px 比で約 26% 多くの行が画面に入る）。枠は詳細と同じ 1px の線と角丸 4pxのまま
  - 一覧とサムネイルでは情報行（`.template-meta`）を隠す
- 保存済みのサムネイル（長辺 120px の JPG）を約 1.25 倍に拡大しているので少しぼける。画を細かくするには 240px のサムネイルを別に保存することになり、容量と索引の追加が要る。別の ADR を立てるまで行わない
- 2 カラムは `minmax(0, 1fr)` で組む。`1fr` だと、折りり返さない長い名前が列を広げて UI が横スクロールしてしまう（実測でセルが 493px になっていた）。名前とグループ名は `min-width: 0` と省略線を持つので、列を固定すれば収まる
- 既存のバグを 1 つ見つけて直した。サムネイルを掴んで行をドラッグすると、ブラウザの画像ドラッグが優先されて `pointercancel` が飛び、ポインタでのドラッグが途中から効かなくなっていた。詳細モードでも同じ（48px のサムネイルを掴めば起きる）。`img.draggable = false` と `dragstart` の `preventDefault` で解消した
- Escape でポップアップを閉じる経路を追加した。トグルのボタンにフォーカスがある状態だとポップアップ側の keydown リスナーに届かないため、開いていても閉じられなかった。絞り込みと一覧メニューにも同じ抜けがあった
