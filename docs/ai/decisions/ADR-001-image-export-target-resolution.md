# ADR-001: 画像書き出し単位の解決（常に画像ノード単位）

- ステータス: 採用（2026-09-24 改訂）
- 日付: 2026-09-24

## コンテキスト

当初はマスクや `clipsContent` 付き FRAME の「見た目」に合わせ、マスク範囲・フレーム範囲を1件として解決した。しかし、`clipsContent` なフレーム内に複数画像があると全画像が1件にまとまり、個別に書き出せないという問題が起きた。ユーザーは複数画像・マスクされた画像・画像を含むフレームを、それぞれ**別の行**として一覧したい。

## 決定

`cbImageExport` の収集では、IMAGE fill を持つ可視ノードそれぞれを**書き出し単位**とする。

- マスクノード（`isMask`）自身はスキップ
- マスク / `clipsContent` へのコンテナ解決は行わない
- 同一 `nodeId` は重複排除する。`visible === false` の枝は走査しない

## 結果

- 一覧・サムネ・`exportAsync` は画像ノード自身に対して行う
- 同一コンテナ内の複数画像も個別行になる
- マスク・クリップ済みの「見た目」との一致は保証しない（元画像がそのまま書き出される）
