# 2026-09-25

## cbImageExport（画像一括書き出しくん）

- インスタンス・スロット内部の画像の行解決を修正
  - `findMaskContainer` / `findClipFrame` の親探索を **INSTANCE 境界で打ち止め**にし、外側フレームへの吸収を防止
  - `findClipFrame` のクリップ候補に **SLOT を追加**。スロット内画像は生の画像ノードではなく `clipsContent=true` のスロット枠を1行とし、切り抜かれた見た目（WYSIWYG）どおりに書き出し（[ADR-001](../docs/ai/decisions/ADR-001-image-export-target-resolution.md)）
- インスタンス内部のノード id（`I…;…;…` 形式）は `figma.getNodeByIdAsync` で再解決できないため、スキャン時に `SceneNode` 参照を保持するキャッシュを追加し、書き出し・フォーカス・リネームのフォールバックに利用
- 一時的な診断ログ（DEBUG）を追加（候補→行の対応、サブツリー診断）。検証後の除去を予定
- 公開申請準備: `manifest.json` の id を Figma 採番の `1685150965482188427` に更新
- 公開用アセットを追加（`icon.png` / `thumbnail01.png`）。タグライン・説明文のコピーは決定済み（ターミナル出力のみ）
- 一覧の書き出し設定（レイヤー名・形式・倍率）を **Figma レイヤーへ反映**。形式・倍率の変更 / 「+」追加 /「✕」削除で `node.exportSettings` を上書きし、空にするとクリア。レイヤー名は従来どおり `RENAME_NODE` で即反映
- 一覧行のホバーで **`hoverEffect` という名前のハイライト**をルート（`figma.currentPage` 直下）に表示。cbTextChecker と同じ塗り（緑 40% + 破線ストローク）・`locked=true`・`visible` 切替で1枚を再利用。スキャン／ページ切替／プラグイン終了で非表示・破棄
- 選択中の対象フレーム自身が一覧に表示されないよう、行が対象フレームそのものに解決される場合に除外
- 行ごとに除外アイコンを追加。クリックで「チェック項目を除外する」ポップオーバーを表示（タイトル + エフェクト / 線 / 角丸のチェックボックス、デフォルト**オン = すべて除外**）。cbTextChecker の ignore パターンに準拠（外側クリックで閉じる・`aria-expanded`）
- 除外設定は**書き出し結果にのみ**反映（元レイヤーの見た目・`exportSettings` には影響しない）
  - 実装: 除外項目がある場合のみ対象ノードを一時クローンし、該当プロパティ（`effects` / `cornerRadius` / `strokes`）をクローンから除去して書き出し後即削除
- 書き出し設定を **レイヤーのエクスポート設定と双方向同期**
  - 「+」追加 /「✕」削除 / 形式・サイズ変更で `node.exportSettings` に上書き反映（空ならクリア）
  - 再スキャン時にレイヤーのエクスポート設定を一覧へ反映（Figma 側で設定された `SCALE` / `WIDTH` / `HEIGHT` の項目をそのまま表示）
- サイズ指定を倍率＋寸法に対応。入力は `1x` / `2x` / `0.5x` / `512w` / `512h` 形式（拡張子なしの純数字は `x` を補完 = 倍率）。SVG / PDF はサイズ指定の影響を受けない
- 行ごとの書き出しアイコンを「+」の左に追加。その行の書き出し設定すべてを書き出し（チェック不要・設定が無ければエラー表示）
- 複数形式（PNG + JPG など）を連続保存できるよう、書き出し先を **フォルダ選択（`showDirectoryPicker`）** に対応
  - クリック時にフォルダを1回選択するだけで、全ファイル（`レイヤー名.ext`）を止まらず同一フォルダへ保存（Chromium の自動ダウンロード規制による欠落を回避）
  - フォルダ選択 API が使えない環境（Figma デスクトップアプリ等）では、全結果を **ZIP（`cbImageExport-時刻.zip`）にまとめて 1 ファイルでダウンロード**（`fflate` で圧縮、重複ファイル名は `_2` 等で一意化）
- 書き出し形式に **WEBP** を追加（Figma に WEBP 書き出しが無いため、PNG でレンダリング後に UI 側で `canvas.toBlob("image/webp")` 変換、画質 0.92）
  - WEBP は Figma レイヤーの `exportSettings` に書けないため、対象フレーム内に **0×0 のセンチネルレイヤー**（`__cb_webp__|<行id>|<サイズ>`・`visible=false` / `locked=true` / 塗りなし）で永続化。設定変更で upsert、解除で削除し、再スキャン時はセンチネルからサイズ付き WEBP 設定を復元（行が消えたセンチネルは掃除）
