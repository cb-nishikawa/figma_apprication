## cbImageExport（画像一括書き出しくん）

- インスタンス・スロット内部の画像の行解決を修正

  - `findClipFrame` のクリップ候補に **SLOT を追加**。スロット内画像は生の画像ノードではなく `clipsContent=true` のスロット枠を1行とし、切り抜かれた見た目（WYSIWYG）どおりに書き出し（[ADR-001](../docs/ai/decisions/ADR-001-image-export-target-resolution.md)）
- インスタンス内部のノード id（`I…;…;…` 形式）は `figma.getNodeByIdAsync` で再解決できないため、スキャン時に `SceneNode` 参照を保持するキャッシュを追加し、書き出し・フォーカス・リネームのフォールバックに利用

- 公開申請準備: `manifest.json` の id を Figma 採番の `1685150965482188427` に更新
- 公開用アセットを追加（`icon.png` / `thumbnail01.png`）。タグライン・説明文のコピーは決定済み（ターミナル出力のみ）
- 一覧の書き出し設定（レイヤー名・形式・倍率）を **Figma レイヤーへ反映**。形式・倍率の変更 / 「+」追加 /「✕」削除で `node.exportSettings` を上書きし、空にするとクリア。レイヤー名は従来どおり `RENAME_NODE` で即反映
- 一覧行のホバーで **`hoverEffect` という名前のハイライト**をルート（`figma.currentPage` 直下）に表示。cbTextChecker と同じ塗り（緑 40% + 破線ストローク）・`locked=true`・`visible` 切替で1枚を再利用。スキャン／ページ切替／プラグイン終了で非表示・破棄
- 選択中の対象フレーム自身が一覧に表示されないよう、行が対象フレームそのものに解決される場合に除外
- 行ごとに除外アイコンを追加。クリックで「チェック項目を除外する」ポップオーバーを表示（タイトル + エフェクト / 線 / 角丸のチェックボックス、デフォルト**オン = すべて除外**）。cbTextChecker の ignore パターンに準拠（外側クリックで閉じる・`aria-expanded`）
- 除外設定は**書き出し結果にのみ**反映（元レイヤーの見た目・`exportSettings` には影響しない）
  - 実装: 除外項目がある場合のみ対象ノードを一時クローンし、該当プロパティ（`effects` / `cornerRadius` / `strokes`）をクローンから除去して書き出し後即削除
- 書き出し設定を **レイヤーのエクスポート設定と双方向同期**
  - 「+」追加 /「✕」削除 / 形式・サイズ変更で `node.exportSettings` に上書き反映（空ならクリア）
  - 再スキャン時にレイヤーのエクスポート設定を一覧へ反映（Figma 側で設定された `SCALE` / `WIDTH` / `HEIGHT` の項目をそのまま表示）
- サイズ指定を倍率＋寸法に対応。入力は `1x` / `2x` / `0.5x` / `512w` / `512h` 形式（拡張子なしの純数字は `x` を補完 = 倍率）。SVG / PDF はサイズ指定の影響を受けない
- 行ごとの書き出しアイコンを「+」の左に追加。その行の書き出し設定すべてを書き出し（チェック不要・設定が無ければエラー表示）
- 複数形式（PNG + JPG など）を連続保存できるよう、書き出し先を **フォルダ選択（`showDirectoryPicker`）** に対応
  - クリック時にフォルダを1回選択するだけで、全ファイル（`レイヤー名.ext`）を止まらず同一フォルダへ保存（Chromium の自動ダウンロード規制による欠落を回避）
  - フォルダ選択 API が使えない環境（Figma デスクトップアプリ等）では、全結果を **ZIP（`cbImageExport-時刻.zip`）にまとめて 1 ファイルでダウンロード**（`fflate` で圧縮、重複ファイル名は `_2` 等で一意化）
- 書き出し形式に **WEBP** を追加（Figma に WEBP 書き出しが無いため、PNG でレンダリング後に UI 側で `canvas.toBlob("image/webp")` 変換、画質 0.92）
  - WEBP は Figma レイヤーの `exportSettings` に書けないため、対象フレーム内に **0×0 のセンチネルレイヤー**（`__cb_webp__|<行id>|<サイズ>`・`visible=false` / `locked=true` / 塗りなし）で永続化。設定変更で upsert、解除で削除し、再スキャン時はセンチネルからサイズ付き WEBP 設定を復元（行が消えたセンチネルは掃除）
- 書き出し形式に **AVIF** を追加。WEBP と同じく PNG レンダリング → UI 側で libavif WASM エンコード（品質 % = 圧縮率入力）で保存し、`__cfg__` センチネルコンテナにサイズ・品質を永続化（圧縮率 % 入力・レイヤー反映除外も同様に適用）。※当初の `canvas.toBlob("image/avif")` 方式は Chromium 非対応で PNG フォールバックしていたため WASM 方式に差し替え済み
- **圧縮率（%）入力**を書き出し設定の形式の右に追加（PNG / JPG / WEBP のみ表示、既定 92・1〜100）
  - PNG: 可逆のため **色数削減（median-cut + Floyd–Steinberg ディザリング + 自前パレット PNG エンコーダ）** で実圧縮。`(256 × q / 100)` 色へ変換（q=100 は変換なし）。CRC-32 は自前実装、deflate は fflate を利用
  - JPG / WEBP: Figma レンダリングは PNG のまま行い、UI 側で `canvas.toBlob("image/jpeg|webp", q/100)` に再エンコード
- センチネルを対象フレーム内の **1 つのコンテナフレーム `__cb_export__`（非表示 + ロック + 0×0）に集約**。中身は `__cfg__|<形式>|<行id>|<サイズ>|<品質>` の 0×0 矩形で、WEBP は常時・PNG/JPG は品質付き設定を保持。再スキャンで同一形式のレイヤー設定を上書きして品質を復元し、行が消えた項目や旧 `__cb_webp__` レイヤーは掃除
- 書き出しファイル名に**サイズサフィックス**を付与。`1x` 以外のとき `レイヤー名_2x.png` / `_512w.jpg` / `_0.5x.webp` のように `_<サイズ>` を拡張子の前に追加（`1x` は従来どおり）。SVG / PDF はサイズ指定が効かないためサフィックスなし
- SVG / PDF では**サイズ入力（倍率・寸法）を非活性化**（`disabled`）。ラスタ形式へ切り替えると入力値は保持され編集可能に戻る
- AVIF のサイズ肥大（＝実体が PNG）を修正。`canvas.toBlob("image/avif")` は Chromium 非対応で **静かに PNG へフォールバック**するのが原因と判明したため、**libavif の WASM エンコーダ（`@jsquash/avif`）** を base64 インラインで同梱し、UI 側で実 AVIF エンコードする方式へ変更
  - 品質 % は libavif の `quality` へマップ（q=100 は lossless）。出力が `ftyp` + `avif`/`avis` ブランドであることを検証
  - `canvasEncode`（JPG / WEBP）には出力 MIME 検査を追加し、同種のフォールバックが起きたらエラーにして静的な失敗を防ぐ
  - 注意: `dist/ui.html` に wasm が base64 インラインされ約 9.4MB、gzip 約 3.0MB に増加（エンコードは同期実行のため大きい画像で僅かに UI が止まり得る）
- PNG 書き出しの色崩れを修正。既定品質 92 が PNG にも適用され**最初の書き出しから 235 色へ量子化**されていたため、PNG は **品質未設定なら無劣化（100・量子化なし）** 扱いに変更
  - `DEFAULT_CONFIG` から `quality` を削除し、`qualityFor` / 品質入力の初期表示を PNG は 100、他形式（JPG / WEBP / AVIF）は 92 に分離
  - センチネルは PNG / JPG を**品質を明示設定したときのみ**保存（WEBP / AVIF は従来どおり常時）にするため、既定のままなら再スキャン後も無劣化が維持される（[spec](../docs/specs/cb-image-export.md) 記載の「品質付き設定時」仕様へ回帰）
  - スライダーで 100 未満にした行は従来どおり色数削減で圧縮
- PNG 圧縮率（%）の量子化エンジンを **高品質化**（従来の median-cut + 無調整ディザの色崩れを改善）
  - ヒストグラム（5bit/チャンネル）を γ 線形化の**立方根（CIE-L* 近似）** 空間で構築し、**k-means++ シード + Lloyd 収束**の重み付きクラスタリングでパレット化。暗部の色判別が潰れず、視覚的に均等な誤差配分
  - ユニーク色 ≤ 色数なら量子化・ディザなしの**完全一致パレット**（フラット UI は品質 % を変えても 1 画素も変わらない）
  - ディザはプレマルチ立方根空間の **Floyd–Steinberg（蛇行スキャン・2 行エラーバッファ）** で α の色滲みを回避
  - 検証: グラデ（q99: 4×4 ブロック平均誤差 0.74 / q50: 1.22）、画面風合成（q99: 0.27 / q50: 0.36）。API（`quantizePng` / `colorsForQuality`）は不変
  - `png.ts` を DOM 非依存の純粋関数（`encodeQuantized` / `quantizeImageData`）に分離し Node 単体テスト可能に
- **フレーム選択エリアに「最近選択したフレーム」履歴（最大20件）を追加**
  - 対象フレーム未選択時にクリック（= `SET_FRAME_FROM_SELECTION` で解決できず `SELECTION_EMPTY`）すると、**.exclude-popover と同形状の履歴ポップオーバー**を表示し、過去に選択したフレームへ 1 クリックで移動できる
  - 履歴は **`figma.clientStorage` に永続化**（プラグインを閉じても保持、最大20件・直近が先頭・id 重複は移動）。起動時に削除済みフレームを掃除
  - 記録は対象確定時（フレーム選択 / 現在の選択から解決）。ポップオーバー下部の「候補一覧から選ぶ…」で従来の検索一覧にもアクセス可能
