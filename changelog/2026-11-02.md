# 2026-11-02

## cbImageExport: 書き出しボタン移動とアプリメニュー

- 書き出しボタンをターゲット行からエクスポートタブ内へ移動。並びは「すべて」→「書き出し」→ URL コピー設定
- ターゲット行にアプリメニュー（ハンバーガー）を再読み込みの左に追加。メニュー内に言語切替の UI 枠（日本語 / English は準備中）を配置（i18n 本体は後続）

## cbImageExport: メニュー配置・Language サブメニュー・フレーム下矢印

- アプリメニューを再読み込みの右へ移動
- メニューの中身を「Language」1 行にし、カーソルを乗せる（またはフォーカス）と左側に日本語 / English のサブメニューを表示（English は準備中で無効）
- エクスポートタブの見出し行を「すべて」左端、書き出し・URL コピー設定を右端に振り分け（space-between）
- 対象フレーム欄の右に下矢印ボタンを追加。クリックで「最近選択したフレーム」を開く（再クリックで閉じる）。これまでは選択が空のときしか履歴を開けなかった

## cbImageExport: 英語対応（i18n）と英語名「Mr. Bulk Image Exporter」

- 共通辞書 `src/i18n.ts`（ja / en）を追加し、UI・プラグイン側の文言を `t()` に置き換え
- アプリメニューの Language → English を有効化。選んだ言語は `clientStorage`（`cbImageExport.locale`）に保存し、次回起動時も反映
- manifest の名前を「画像一括書き出しくん / Mr. Bulk Image Exporter」と併記。プラグイン内タイトルは言語に追従（ウィンドウタイトルは次回起動時）
- 共有パック README の見出しも両方の名前を併記
- 設計判断: [ADR-022](../docs/ai/decisions/ADR-022-image-export-i18n.md)

## cbImageExport: フレーム選択エリアのインライン検索

- フレーム選択欄をテキスト入力に変更。フォーカスや入力で候補一覧が直下に開き、名前で絞り込める（↑↓・Enter・Esc 対応）
- 下矢印は同じ候補一覧の開閉に変更。「最近選択したフレーム」パネルと「候補一覧から選ぶ…」は廃止
- キャンバスの選択からフレームを設定する操作は、入力左のアイコンボタンに移動
