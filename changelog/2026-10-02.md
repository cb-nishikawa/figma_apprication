## cbTextChecker（テキストチェック + OCR 比較）

- **検索キーワード行・比較ペア行・画像行の三点リーダメニューに「非表示」を追加**（クリアと削除の間。非表示中は「表示」に切り替わる）
  - 非表示中は、その行の入力エリア（テキストエリア、ターゲット選択、間の ↔ アイコン）を非活性表示にし、クリアも無効化
  - 非表示の行は、検索クエリ・比較ペア（`ComparePair.hidden`）・OCR 表示と画像比較の対象から除外し、結果とハイライトにも出さない
  - 比較ペアがすべて非表示のときは「表示中の比較ペアがありません」と表示
- **オーバーレイのレイヤー名に起動ごとのセッション ID を付与**し、自分のレイヤーだけを削除するように変更。複数人で同時に使っても互いのハイライトを消さない（[ADR-002](../docs/ai/decisions/ADR-002-session-scoped-overlays.md)）
  - 対象候補一覧から `__CB_TC_` で始まるオーバーレイを除外
- **ターゲット選択済みのピッカー（検索・比較 A/B・画像・画像比較ターゲット）にホバーすると、対象レイヤーを緑の破線枠（線の太さ 10px・破線間隔 10px・塗りなし・レイヤーの外側に描画）で表示**
  - 枠はハイライトプールとは別の専用レイヤー `__CB_TC_TARGET__@<セッションID>` で、ピン留めハイライトの表示状態には影響しない
  - 未選択・非活性（非表示行・OCR 実行中）のピッカーでは出さない。別ページのノードも出さない

- **色選択の見本の緑（#00c853）を、キャンバスのハイライトと同じ #00ff40 に統一**。ハイライト 4 色の定義を `src/highlightPalette.ts` の 1 か所にまとめ、UI の見本とキャンバスの塗り（ターゲット破線枠を含む）が同じ値を参照するように変更
- **デザイン用マークダウン [`_example/cbTextChecker-design.md`](../_example/cbTextChecker-design.md) を追加**（`_example/test.md` と同じ DESIGN.md 形式・英語）。色・文字・角丸・余白・コンポーネントのトークンを ui.css / highlight.ts の実装値から抜き出し、キャンバス上のハイライト 4 色・ターゲット破線枠・OCR ラベルも記載

## cbTemplatePalette（テンプレパレットくん）新規

- **新しいプラグインを追加**。Figma で選択した frame / section / group のまとまりを保存し、別のファイルでも一覧から選んで、今見ている画面の中央に複製できる
  - 「＋ 選択中の要素を保存」で一覧に追加（複数選択は 1 件にまとめる）。行をクリックで選択し、「Figma に複製」かダブルクリックで配置。「⋯」メニューで名前の変更と削除、上部の入力欄で絞り込み
  - ノードツリーを独自 JSON に変換し、サムネイルと一緒に `figma.clientStorage` に保存（約 5MB の上限と使用量をフッターに表示）。インスタンスは detach 相当、スタイル・変数の紐付けは外して値だけ残し、無いフォントは置き換える（[ADR-003](../docs/ai/decisions/ADR-003-template-palette-serialization.md)、仕様は [`docs/specs/cb-template-palette.md`](../docs/specs/cb-template-palette.md)）
  - UI は [`_example/cbTextChecker-design.md`](../_example/cbTextChecker-design.md) のトークンに合わせた
  - manifest の `id` は開発用の仮の値。公開時に Figma で発行した ID に差し替える
- **保存容量を節約**（5MB の上限は Figma の固定値で引き上げられないため）
  - 画像のバイト列は保存しない。複製時は、画像の塗りを常に単色（`#D9D9D9`）に置き換えて件数を通知する（同じファイルに元の画像があっても、初版で保存した画像データがあっても使わない）
  - ノードツリーを gzip（fflate）で圧縮して保存する（保存形式 version 2。初版の version 1 も読める）。サムネイルは長辺 120px の JPG にした
- **サムネイルを複製結果と同じ見た目に**。元のノードではなく、保存データを画面外に一時的に復元して書き出す（画像は単色になる）。既存のテンプレートは起動時に、ファイルから読み込んだものは読み込み時に作り直す。起動時には初版（version 1）の本体も version 2 に移し、使わない画像データを消す
- **コンポーネントを登録できるように**。COMPONENT か COMPONENT_SET を 1 つだけ選んで保存すると、コンポーネントのテンプレートになる（一覧に「コンポーネント」バッジ）。複製すると、既存とは別の新しいコンポーネントとして置く（[ADR-004](../docs/ai/decisions/ADR-004-component-templates.md)）
  - 同じファイルでは元を `clone()` するので、中のインスタンス・スロット・プロパティ・オーバーライドがすべて残る（画像だけ単色に塗り替える）
  - 別のファイルでは保存データから組み立て直す。プロパティ定義と参照、スロット、インスタンスとそのオーバーライドを作り直す。中のインスタンスの元コンポーネントが無ければ、それも新しく作ってセクション「テンプレパレット: 部品」に並べ、インスタンスのまま残す
  - あわせて、レイアウトのテンプレートでもスロットの中身がスキップされていたのを、フレームとして保存するよう直した
- **ファイルへの書き出し・読み込みを追加**。一覧の見出しの「読み込む」「すべて書き出す」と、行の「⋯」メニューの「ファイルに書き出す」で、`*.cbtemplate.json`（画像は含めない）をパソコンに保存・読み込みできる。容量を超える分は読み込まずに知らせる（[ADR-003 の追記](../docs/ai/decisions/ADR-003-template-palette-serialization.md)）
- **保存セクションの説明文を削除**。冒頭のリード文（`Figma で frame・section・group・コンポーネントを選択して保存します。保存した要素は別のファイルでも複製できます。`）と、未使用になった `.lead` の CSS を削除
- **「frame・section・group・コンポーネントを選択してください」を削除**。選択 0 件のときは案内文を出さず、保存ボタンを無効化した。ヒント欄は選択があるときだけ表示する
- **「読み込む」「すべて書き出す」を一覧の見出しからフッターへ移動し、アイコンボタンに**。インライン SVG（読み込みは上向き、書き出しは下向きの矢印 + トレイ、28px・枠あり）で、`Figma に複製` の左に並べる。ラベルは `aria-label` に残した
  - あわせて未使用になった `.list-actions` と `.btn-link` の CSS を削除し、`.footer-actions` と `.btn-icon`（28px・白地・`#d0d0d0` の枠・hover `#f5f5f5`）を追加。幅が狭いときは左の使用量テキストが省略される
- **絞り込みを「保存した要素 ◯件」の右のアイコンボタン＋ポップアップに変更**。ファネルアイコンの 28px ボタン（cbTextChecker と同じ `.btn-icon`）をクリックで開き、その中に「名前で絞り込み」の入力欄を出すようにした（cbTextChecker の無視設定・候補ピッカーのポップオーバーに倣った方式。`position: relative` のラッパ + 絶対配置のカード + 外部クリック・`Escape` で閉じる）
  - 一覧の見出しの横にフルワイドで出ていた入力欄を撤収し、ポップアップの中へ移動
  - 絞り込み文字列が入っているときはアイコンの枠と色を `#18a0fb` にして、絞り込み中であることが分かるようにする
  - 行の「⋯」メニューを開くと閉じる（互いに同時に開かない）
- **操作をすべてフッターに集約し、保存セクションを廃止**。冒頭の「＋ 選択中の要素を保存」とその下の区切り線（`<hr>`）を削除し、保存ボタンはフッターの読み込み・書き出しの右に「追加」として移動した。フッターは「読み込む / 書き出す / 追加 / 複製」の並び
  - 「追加」は Figma で要素を選択しているときだけ、「複製」は一覧の要素を選択しているときだけ表示する（無効化ではなく非表示）。両方そろうのはその両方を満たすとき
  - 「Figma に複製」は「複製」に改めた。両方とも `.btn-primary`（青塗り）で同じ見た目
  - 選択中の要素の説明は「選択中の 3 件を 1 つのテンプレートとして保存します」から「3 件を選択中」「コンポーネントを選択中」と短くし、フッターの左（使用量の下）に縦に積んで表示する
  - 未使用になった `.divider` と `.btn-add-full` の CSS を削除し、`.footer-info` を追加
- **キャンバス上の選択と一覧の選択を互いに排他にした**
  - Figma の画面で要素を選択すると、一覧の選択が解除される
  - 一覧の行を選ぶと、Figma 側の選択が解除され、フッターの「追加」は出なくなる
  - 一覧の行でないところ（余白、見出し、使用量など）をクリックすると、一覧の選択が解除される
  - 選択を保つのは一覧の行・行の「⋯」メニュー・名前の変更入力欄・フッターのボタン・絞り込みのポップアップ
  - Figma の選択変化には原因が返らないため、プラグイン自身が選択を変えたとき（複製して置いたとき）は解除しない。「複製」の後も同じ要素を続けて置ける
