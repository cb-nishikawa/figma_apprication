## cbImageExport（画像一括書き出しくん）

- 新規プラグイン `cbImageExport/` を追加
- 選択フレーム内の可視画像を一覧（名前検索・一括形式は後に廃止）
- マスク／クリップは親範囲を1件として扱う（後に画像ノード単位へ改訂）
- 一覧を常に画像ノード単位に変更し、フレーム内の複数画像・マスクされた画像・画像を含むフレームを個別行として表示（[ADR-001](../docs/ai/decisions/ADR-001-image-export-target-resolution.md) 改訂）
- 書き出し機能: PNG / JPG / SVG / PDF。倍率は数値入力（2 = 2倍 / 0.5 = 半分 / 未入力 = 等倍。PNG・JPG に適用）
- UI: 検索・一括形式・グローバル倍率を廃止。書き出しボタンをヘッダーへ移動し、チェック済み画像のみ書き出し。「すべて」チェック付き
- 画像ごとの書き出し設定: 「+」で倍率・形式の設定行（「-」で削除）を複数追加。設定行は「+」を押すまで非表示
- レイヤー名を編集可能にし、Figma 上のレイヤー名と書き出しファイル名へ反映。親名表示は削除
- 対象フレームの選択を cbTextChecker と同じピッカー方式（SECTION / FRAME / INSTANCE / GROUP を一覧、選択からの解決または候補ポップオーバー）に変更し、選択状態の自動追従は廃止
- ヘッダーの「書き出し」「再読み込み」をアイコンボタン化（再読み込みは cbTextChecker と同じリロードアイコン）
- マスク / `clipsContent` 枠に画像が1枚だけの場合は**その枠自体を1行**として一覧し、サムネイル・書き出し・リネーム・フォーカスの対象にする。複数画像の枠は画像ノード単位のまま（[ADR-001](../docs/ai/decisions/ADR-001-image-export-target-resolution.md) 改訂）
