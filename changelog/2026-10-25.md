# 2026-10-25

## cbComponentExplorer

- **Components の見出しを検索アイコンに置き換え**
  - 見出しを削除し、虫眼鏡ボタン（cbTextChecker と同じ 28px / `.btn-icon`）を置いた
  - ボタンを押すと、cbTextChecker の「無視する文字列」と同じポップアップを下に開く。名前で部分一致で絞り込む
  - 絞り込み中はボタンを強調表示する
  - レイヤー順は `filterLayerItems` で絞り、見出しは中に一致があるときだけ残し、一致箇所は自動で開く
  - 名前順も名前・バリアント名で絞り、セット名一致なら全バリアントを残す
  - 一致が 0 件なら「一致する Component がありません」と表示する
- **Shift+クリックでアコーディオンの全下位を開閉**
  - アコーディオンの矢印または見出しの空いたところを Shift+クリックすると、その配下（子・孫以下）すべてを開閉する
---

- **検索対象をコンポーネントとインスタンスに拡張**
  - 虫眼鏡ポップアップに「コンポーネント」「インスタンス」のチェックボックスを追加（デフォルト両方 ON）
  - インスタンス名・メインコンポーネント名で検索できる（frame/section/group は検索対象外）
  - レイヤー順はレイヤー構造を維持したまま、マッチしたノードまでの経路のみ表示し、自動で展開する
- **検索対象のチェックを仕様どおりに効かせた**
  - チェックが付いている種類だけを一覧に出す（「コンポーネント」= 定義とコンポーネントセットの行、「インスタンス」= インスタンスの行）。検索文字が空でも効く
  - チェックを外した種類の行は中身ごと出さない（例: コンポーネントを外すと、定義の中のインスタンスも出ない）。これまではインスタンスを外しても、中に一致があると入れ物として残っていた
  - 一致した行は、中身を検索文字では絞らずチェックだけで絞る。開くのは、子孫に一致がある行と残った見出しだけ
  - 名前順にもインスタンスの行（レイヤー名、下にメイン名、「メインへ」）を出す。これまではインスタンスが一致すると親のコンポーネントの行を出していた
  - 0 件の文言を「一致する項目がありません」にし、検索文字があるかどちらかのチェックを外しているときに出す。虫眼鏡ボタンの強調も同じ条件にした
  - typecheck・build は通る。`filterLayerItems` は node で確認した（インスタンス・コンポーネントを外したとき、空文字、入れ子の一致、0 件）。Figma の実機は未確認
