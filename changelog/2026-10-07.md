# 2026-10-07

## cbTemplatePalette（テンプレパレットくん）

- **グループの「移動」でカテゴリを変えても一覧が変わらなかったのを直した**（[ADR-009 の追記](../docs/ai/decisions/ADR-009-template-palette-group-categories.md)）
  - グループのカテゴリだけを書き換えていて、中のテンプレートのカテゴリは元のままだった。一覧はテンプレートのカテゴリで絞るので、グループが今のカテゴリに残って見えていた
  - いまはグループのカテゴリと一緒に、中のテンプレートのカテゴリも同じものに書き換える（`setTemplatesCategory` で index を 1 回だけ保存）。UI 側でも先に書き換えるので、返事を待たずに今の一覧から消える
- **グループの最後の 1 件を別カテゴリのルートへ出すと、空のグループが移動先のカテゴリにも出ていたのを直した**
  - 中身が 0 件のグループはどのカテゴリにも出していたため。いまはグループのカテゴリが今選んでいるカテゴリと同じときだけ出す
  - 新しく作るグループには、今選んでいる保存先カテゴリを付ける（`ADD_GROUP` に任意の `category`）。未設定以外を見ているときに、作った直後に消えないようにするため
- typecheck と build は通る。一覧の切り替わりは実機でのみ確認
- **カテゴリボタンを文字ボタンにした**（[ADR-008 の追記](../docs/ai/decisions/ADR-008-template-palette-categories.md)）
  - タグのアイコンをやめ、今のカテゴリ名（「未設定」など）と ▾ を出す。幅は 96px 固定で、はみ出した名前は省略線。省略しない名前はツールチップに出る
  - 未設定以外を選んでいる間は、これまでどおり青い枠と文字になる
- **一覧の「⋯」に「カテゴリを削除」を足した**（[ADR-008 の追記](../docs/ai/decisions/ADR-008-template-palette-categories.md)）
  - 今選んでいるカテゴリを、中のテンプレートとグループごと消す。未設定のときは押せない
  - 「⋯」の中で「「名前」と中のテンプレート N 件・グループ M 件を削除します」と確認してから消す。消したらレジストリからも外し、保存先は「未設定」に戻る
  - `DELETE_CATEGORY` を足し、`deleteTemplates` でテンプレートとグループをまとめて消す
- typecheck と build は通る。ボタンの見た目と削除の確認は実機でのみ確認
- **一覧の「⋯」の一番下に「設定」を足した（画面のみ）**
  - 押すとダイアログで「保存先」（ローカル / 外部ストレージ）、サービス（Supabase のみ）、Project URL、Publishable Key、ID、パスワード、「接続テスト」を出す
  - ローカルを選んでいる間は外部ストレージの項目を薄くして触れなくする
  - 外部ストレージはまだ実装していない。選んでも保存先はローカルのまま、入力も保存しない（閉じると次に開いたときは空）。「接続テスト」は「外部ストレージはまだ使えません（準備中）」と出すだけ
  - 「閉じる」・Esc・カードの外のクリックで閉じる。プラグインの高さが低いときはカードの中でスクロールする
- **外部ストレージに Google Drive を足した**（[ADR-010](../docs/ai/decisions/ADR-010-template-palette-google-drive.md)）
  - `storageAdapter.ts` の `StorageAdapter`（`get` / `set` / `remove`）を置き、`storage.ts` の `clientStorage` 呼び出しをすべてここ経由にした。`LocalStorageAdapter` は `clientStorage` をそのまま呼ぶだけで、ローカルの挙動とキーは変えていない
  - `GoogleDriveStorageAdapter`（`googleDrive.ts`）: 保存フォルダに `metadata.json`・`index.json`・`tree.json`・`categories.json`・`items/<id>.json` を置く。`Uint8Array` は `{"$u8": base64}`。容量の上限は持たない
  - 認証は Cloudflare Worker（`cbTemplatePalette/worker/`）。`client_secret` とリフレッシュトークンは Worker にだけ置き、プラグインは取り消し可能な `sessionToken` だけを `clientStorage` に、アクセストークンはメモリにだけ持つ。権限は `drive.file` のみで、フォルダは Worker の Google Picker のページで選ぶ
  - 設定画面: サービスに「Google Drive」を足し、選んだときだけ「Googleアカウントで接続」・接続状態・「フォルダを選択」・現在の保存先を出す。Supabase の項目は Supabase を選んだときだけ出す。「閉じる」を「キャンセル」と「保存」にし、保存を押すまで保存先は変えない
  - 接続テストは認証 → Drive API → フォルダの権限 → 読み書きの順。成功は「接続成功」、失敗は決まった文言だけを出し、API のエラーは出さない
  - Drive に届かないときは黙ってローカルに戻さず、一覧の上に案内と「設定を開く」を出す。切り替えではデータをコピーも削除もしない
  - `manifest.json` の `networkAccess` に `https://www.googleapis.com` と Worker のドメインを足した
  - typecheck・build・pack:share、Worker の型チェックと `wrangler deploy --dry-run` は通る。Google Cloud と Cloudflare の設定をしないと接続できず、実機での確認はまだ
  - **2026-10-09 に、設定ダイアログと一緒に Google Drive 対応を削除した**（[changelog/2026-10-09](2026-10-09.md)、[ADR-011](../docs/ai/decisions/ADR-011-template-palette-shared-categories.md)）
