# 2026-10-09

## cbTemplatePalette（テンプレパレットくん）

- **共有カテゴリ（Cloudflare R2）を足し、保存先の設定ダイアログと Google Drive をやめた**（[ADR-011](../docs/ai/decisions/ADR-011-template-palette-shared-categories.md)、[ADR-010](../docs/ai/decisions/ADR-010-template-palette-google-drive.md) は廃止）
  - 「未設定」と通常のカテゴリは常にローカル（`clientStorage`）。「⋯」→「設定」（保存先の切り替え・Supabase の仮画面）は削除した
  - Google Drive 対応（`googleAuth.ts` / `googleDrive.ts` / `storageSettings.ts`、OAuth 用 Worker `cbTemplatePalette/worker/`）を丸ごと削除した。公開前だったのでデータの移行は無い。clientStorage に残った `storageSettings` / `googleSession` は読まなくなるだけで消さない
  - R2 は各自がデプロイする Worker（`cbTemplatePalette/r2-worker/`）を経由する。プラグインには Worker の URL・アクセストークン・スペース名だけを入れ、R2 のアクセスキーは置かない
  - 一覧の「⋯」→「共有カテゴリを追加…」で、R2 のスペースを 1 つのカテゴリとして足せる。同じ保存先を複数の人が追加すると、同じテンプレートを使える
  - 共有カテゴリはカテゴリメニューで「R2」の印が付く。「カテゴリを削除」は「カテゴリを外す」になり、登録を消すだけで保存先のデータは残す。名前の変更は自分の一覧での表示名だけ
  - 別の保存先のカテゴリへの移動は、移動先に保存してから移動元を消す
  - ストレージに触るメッセージは 1 つずつ順に処理し、その間だけカテゴリの保存先に差し替える（`stores.ts`）。UI はカテゴリを変えるたびに `VIEW_CATEGORY` を送る
  - 保存先に届かないときは、一覧の上に「共有カテゴリ「名前」」と案内を出す（「設定を開く」ボタンは削除）
  - manifest の `networkAccess` は `https://*.workers.dev` だけにした（`www.googleapis.com` と認証用 Worker を外した）
- typecheck・build・pack:share、`r2-worker` の `npm run check`（tsc と `wrangler deploy --dry-run`）は通る。R2 Worker のデプロイと、共有カテゴリの読み書きは実機で未確認
