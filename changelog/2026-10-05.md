# 2026-10-05

## cbTemplatePalette（テンプレパレットくん）

- **保存したテンプレートをグループにまとめ、並び順を自分で決められるようにした**（[ADR-005](../docs/ai/decisions/ADR-005-template-palette-groups.md)、仕様は [`docs/specs/cb-template-palette.md`](../docs/specs/cb-template-palette.md)）
  - 一覧の見出しの「⋯」メニュー（絞り込みの右隣）→「グループを追加」でグループを作れる。開いた直後に名前を変更する欄を出す。初期名は「グループ 1」「グループ 2」…
    - ポップアップの「グループを追加」は横一列で表示する。絶対配置（`width: auto`）に中の項目の `width: 100%` が重なって最小幅になり、6 文字が縦に積まれていたため。最小幅を入れ、文字サイズを 11px にした
  - グループにも「⋯」メニューがあり、「名前を変更」「削除」ができる
    - グループを削除しても中のテンプレートは消えず、元の位置にルートへ戻す。中での並びは保つ
  - グループは 1 階層だけ。ルートにはグループとテンプレートが混在する
  - 作った直後の空のグループも（絞り込み中でなければ）一覧に出る。入れられる状態にならないとグループを作れないため。グループを作ると一覧の末尾に追加されるので、見える位置までスクロールする
  - 行やグループをドラッグして並べ替えられるようにした（Pointer Events。4px 以上動いた時点で開始）。行の上端・下端にドロップすると前後に移動し、中央やグループ本体にドロップすると中に入る。`Escape` で取り消す。グループを別のグループに入れても動かない
  - 行の「⋯」メニューに「← 移動」を追加。ホバーでサブメニューが開き、「グループなし」とすべてのグループ（件数つき）が並ぶ。クリックでそのグループの末尾に入る。現在いる場所は灰色で選べない。ドラッグを使わずに移動できる
  - **グループをアコーディオンでたためられるようにした**（[ADR-005 の追記](../docs/ai/decisions/ADR-005-template-palette-groups.md)）
    - グループ名の左のシェブロンを押すとたためる／開く。開閉状態は `cbTemplatePalette.tree` の `collapsed` に保存するので、プラグインを開き直しても同じ状態に戻る
    - シェブロンは独立したボタンなので、押してもグループは選択されず、ドラッグも始まらない
    - 絞り込み中は、たたんでいても開いた状態で描く。一致したテンプレートが隠れると検索結果を誰も読めないため。絞り込みを消すと元の状態に戻る
    - たためたグループにテンプレートをドロップすると、自動で開いて中に入る。中身が見えないと移動できたかどうか分からないため
    - 件数（例: 12件）はたたんだまま出す。何が隠れているかが分かる
    - ファイル（`*.cbtemplate.json`）には開閉状態を書かない。ファイルが持つのは中身の構成と並び順だけで、読み込んだグループは全部開いた状態で出る
- **並び順とグループを `cbTemplatePalette.tree` に保存**。テンプレートのメタデータは `cbTemplatePalette.index` のまま
  - 読み込むときにツリーを index と照合する。index に無い id を落とし、ツリーが知らない id をルート先頭に足し、同じ id は最初の 1 箇所だけ残す。グループ機能より前に保存したテンプレートも自動でルート先頭に出る
  - 並べ替えの処理を新しい `src/tree.ts` の純関数に切り出した（Figma API に依存しない）。この範囲は node で直接動かして 47 ケースを確認した
- **グループもファイルへの書き出し・読み込みの対象に**（`*.cbtemplate.json` を version 3 に拡張。version 2 のファイルも読める）
  - 1 件だけ書き出すときは平坦に書き出す（グループを作らない）
  - `tree` のない version 2 ファイルはルートに置く。version 3 でも `tree` が所述の id を網羅していなければ、足りない分をルート末尾に足す。テンプレートとグループの id は読み込み時に振り直す
- **一覧を `role="tree"` に変更**。グループの見出しに件数を出す（「12件」、絞り込み中は「12件中 3件」）。中のリストは左に縦線で字下げ
