# 2026-10-05

## cbTemplatePalette（テンプレパレットくん）

- **保存したテンプレートをグループにまとめ、並び順を自分で決められるようにした**（[ADR-005](../docs/ai/decisions/ADR-005-template-palette-groups.md)、仕様は [`docs/specs/cb-template-palette.md`](../docs/specs/cb-template-palette.md)）
  - 一覧の見出しの「⋯」メニュー（絞り込みの右隣）→「グループを追加」でグループを作れる。開いた直後に名前を変更する欄を出す。初期名は「グループ 1」「グループ 2」…
    - ポップアップの「グループを追加」は横一列で表示する。絶対配置（`width: auto`）に中の項目の `width: 100%` が重なって最小幅になり、6 文字が縦に積まれていたため。最小幅を入れ、文字サイズを 11px にした
  - グループにも「⋯」メニューがあり、「名前を変更」「削除」ができる
    - グループを削除しても中のテンプレートは消えず、元の位置にルートへ戻す。中での並びは保つ
  - グループは 1 階層だけ。ルートにはグループとテンプレートが混在する
  - 作った直後の空のグループも（絞り込み中でなければ）一覧に出る。入れられる状態にならないとグループを作れないため。グループを作ると一覧の末尾に追加されるので、見える位置までスクロールする
  - 行やグループをドラッグして並べ替えられるようにした（Pointer Events。4px 以上動いた時点で開始）。行の上端・下端にドロップすると前後に移動し、中央やグループ本体にドロップすると中に入る。`Escape` で取り消す。グループを別のグループに入れても動かない
  - 行の「⋯」メニューに「← 移動」を追加。ホバーでサブメニューが開き、「グループなし」とすべてのグループ（件数つき）が並ぶ。クリックでそのグループの末尾に入る。現在いる場所は灰色で選べない。ドラッグを使わずに移動できる
  - **グループをアコーディオンでたためられるようにした**（[ADR-005 の追記](../docs/ai/decisions/ADR-005-template-palette-groups.md)）
    - グループ名の左のシェブロンを押すとたためる／開く。開閉状態は `cbTemplatePalette.tree` の `collapsed` に保存するので、プラグインを開き直しても同じ状態に戻る
    - シェブロンは独立したボタンなので、押してもグループは選択されず、ドラッグも始まらない
    - 絞り込み中は、たたんでいても開いた状態で描く。一致したテンプレートが隠れると検索結果を誰も読めないため。絞り込みを消すと元の状態に戻る
    - たためたグループにテンプレートをドロップすると、自動で開いて中に入る。中身が見えないと移動できたかどうか分からないため
    - 件数（例: 12件）はたたんだまま出す。何が隠れているかが分かる
    - ファイル（`*.cbtemplate.json`）には開閉状態を書かない。ファイルが持つのは中身の構成と並び順だけで、読み込んだグループは全部開いた状態で出る
- **並び順とグループを `cbTemplatePalette.tree` に保存**。テンプレートのメタデータは `cbTemplatePalette.index` のまま
  - 読み込むときにツリーを index と照合する。index に無い id を落とし、ツリーが知らない id をルート先頭に足し、同じ id は最初の 1 箇所だけ残す。グループ機能より前に保存したテンプレートも自動でルート先頭に出る
  - 並べ替えの処理を新しい `src/tree.ts` の純関数に切り出した（Figma API に依存しない）。この範囲は node で直接動かして 47 ケースを確認した
- **グループもファイルへの書き出し・読み込みの対象に**（`*.cbtemplate.json` を version 3 に拡張。version 2 のファイルも読める）
  - 1 件だけ書き出すときは平坦に書き出す（グループを作らない）
  - `tree` のない version 2 ファイルはルートに置く。version 3 でも `tree` が所述の id を網羅していなければ、足りない分をルート末尾に足す。テンプレートとグループの id は読み込み時に振り直す
- **使用量をフッターに出し、選択中の件数の下に置いた**。その下に細いバーを添える
  - 数値（`使用量 3.2MB / 5.0MB`）の下に高さ 2px のバー。80% 以上で危険色 `#b00020` に変え、上限を超えた分は 100.0% に留める
  - 処理中（`保存しています…` など）は同じ行がメッセージに置き換わり、バーも一緒に隠す。進捗用の行は増やさない
  - 3 つの表示モードで同じフッターを使うので、モードごとの変更はない
- **使用量が一度も表示されていなかったバグを直した**
  - `usage` を宣言して `renderStatus()` から読んでいたが、`TEMPLATES` メッセージから値を代入する文が抜けていた。よって `usage.quota` は 0 のまま「使用量」の行は常に空だった
  - 仕様には「フッターに使用量を表示する」と書かれていたので、表示されていないことに気づいていなかった
  - `case "TEMPLATES"` で `usedBytes` / `quotaBytes` を受け取るようにした
- **`manifest.json` のプラグイン ID を正式な値にした**
  - 開発用の仮 id `cb-template-palette-dev` から `1689154013319512725` へ。Figma は ID でプラグインを区別するため、この変更で**今まで `cb-template-palette-dev` として保存したテンプレートは新しい ID からは見えなくなる**（同じ端末でも別プラグイン扱い）
  - 開発中に保存したデータを引き継ぎたい場合は、いったん旧 id で書き出して `*.cbtemplate.json` としてから新しい id で読み込む
  - 共有パック（`npm run pack:share`）は `manifest.json` から作られるので、生成物も同じ id になる
- **frame / section / コンポーネント以外も保存できるようにした**（[ADR-003 の追記](../docs/ai/decisions/ADR-003-template-palette-serialization.md)）
  - 矩形・楕円・ポリゴン・星・直線・ベクター・ブール演算・テキストを 1 つだけ、あるいは複数選んで保存できる。シリアライズと復元はもともと子としては扱っていたが、ルートで受け付ける型の許可リストが frame / section / group / component / instance しかなかった
  - 許可リストはシリアライズ側の集合定数を共有するようにした。型を 1 つ増やすときに 2 箇所を直さなくてよい
  - スライスなど復元できない型を 1 つでも混ざらせると、保存せずエラーにする。保存対象の件数を 0 としてボタンを出し、ヒントに「保存できない要素が N 件あります」と出す
    - 以前は対象外を黙って捨てて保存していた。ユーザーは何を失ったのか分からなくなるためやめた
    - ボタンが隠れていても `handleSave()` 側でも同じ判定を行う
    - 子に混ざった対象外のノードは、従来どおりスキップして件数を通知する
  - 複数選択のサムネイルが 1 件目しか出ていないのを直した。全ルートを画面外に復元して書き出す。複数なら一時グループにまとめるが、section はグループにできないのでその場合は 1 件目だけを使う
- **一覧の表示モードを 3 つに分けた**（[ADR-006](../docs/ai/decisions/ADR-006-template-palette-view-modes.md)）
  - 絞り込みアイコンの左に表示切り替えのボタンを置き、ポップアップで「詳細」「一覧」「サムネイル」を選ぶ。ボタンの絵は現在のモード
  - 詳細 = 今の見た目。一覧 = 32px のサムネイルと名前のみ。行の高さが 60px から 44px になり、同じ画面により多くの行が入る
  - サムネイル = 2 カラムでサムネイルを大きくし、画像を上・名前を下に置く
  - モードは CSS のクラスだけで切り替える（`is-list` / `is-grid`）。行の HTML は作り直さないので、選択・名前変更・複製・削除・グループの開閉はそのまま動く
  - モードは `cbTemplatePalette.viewMode` に保存する。`tree` にもファイルにも書かない（見た目の好みで、端末ごとに違うもの）
  - サムネイルモードでも並べ替えは使う。行の左右の半分で前後を決め、ヒントは左右の縦線。グループの見出しは 2 セルを使い切って 1 行、中身も 2 カラム
  - サムネイルモードは 360px 幅でセルが 162px。保存済みのサムネイル（長辺 120px）を約 1.25 倍に拡大しているので少しぼける
  - 折りり返さない長い名前があっても 2 カラムを保つ（列は `minmax(0, 1fr)`）。名前とグループ名は省略線になる
  - `Escape` でポップアップを閉じる経路を追加した。トグルのボタンにフォーカスがあるだけだとポップアップ側の keydown に届かないため。絞り込みと一覧メニューにも同じ抜けがあった
- **サムネイルを掴んで行をドラッグできないバグを直した**
  - ブラウザの画像ドラッグが優先されて `pointercancel` が飛び、ポインタでのドラッグが途中から効かなくなっていた。詳細モードでも、48px のサムネイルを掴めば起きていた
  - `img.draggable = false` と `dragstart` の `preventDefault` で解消
- **一覧を `role="tree"` に変更**。グループの見出しに件数を出す（「12件」、絞り込み中は「12件中 3件」）。中のリストは左に縦線で字下げ
